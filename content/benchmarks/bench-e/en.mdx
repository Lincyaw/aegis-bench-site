## Setting<About text="The agent works on a small Python codebase in an isolated development environment, with the same information and tools an engineer has for the same requirement." />

<Flow>
  <Step title="The agent receives">The requirement, the full repository and a development environment it can run.</Step>
  <Step title="How it works">It can read and search the code, create and edit files, run commands and the existing tests; it cannot reach the network.</Step>
  <Step title="What it submits">Its changes to the repository, and a report.json explaining each change. It submits once.</Step>
</Flow>

<Sample task="task-001" title="报告的 JSON 输出">
为 ledger 的 report 命令增加 JSON 输出：传入 --format json 时，以 JSON 对象输出各账户的合计与总计；不传或传入 --format table 时，输出保持现在的表格不变。
</Sample>

The sample is quoted as the task gives it; tasks are published in the language they were written in.

## Evaluation<About text="Each task is judged by tests and checks the agent never sees, and every model runs under the same conditions." />

<Flow>
  <Step title="What is graded">The agent's changes and report.json, rebuilt in a fresh environment.</Step>
  <Step title="Checks">The existing tests, tests of the new feature, the unchanged existing output, and that no existing test was changed.</Step>
  <Step title="Scoring">A run passes when every check passes; the score is each task's pass rate.</Step>
</Flow>

<Facts>
  <Fact label="Metric">Pass rate; higher is better</Fact>
  <Fact label="Runs">1 run per task and combination</Fact>
  <Fact label="Budget">At most 50 turns per run</Fact>
  <Fact label="Same conditions">The same harnesses, turn budget and execution environment</Fact>
</Facts>
