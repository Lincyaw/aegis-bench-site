## Setting

The agent works in an isolated development environment and gets the same information and tools an engineer would have for the same request.

<Flow>
  <Step title="The agent receives">The requirement, the complete repository and a working development environment.</Step>
  <Step title="How it works">It may read and write the repository, run commands and run the existing tests; it has no outside network.</Step>
  <Step title="What it submits">Its changes to the repository. It may submit several times; the last submission counts.</Step>
</Flow>

<Sample task="task-017" title="订单分页查询">
为订单服务新增按状态筛选的分页查询接口。已有接口的行为与返回格式保持不变，新增接口的鉴权方式与现有接口一致。
</Sample>

The sample is quoted as the task gives it; tasks are published in the language they were written in.

## Evaluation

Each task is decided by tests in the repository that the agent never sees, and every model runs under the same conditions.

<Flow>
  <Step title="What is graded">The agent's submitted changes, rebuilt in a fresh environment.</Step>
  <Step title="Checks">Functional and regression tests, run together after submission.</Step>
  <Step title="Scoring">A task passes when every test passes; the score is the mean pass rate over 5 runs per task.</Step>
</Flow>

<Facts>
  <Fact label="Metric">Pass rate; higher is better</Fact>
  <Fact label="Runs">5 independent runs per task</Fact>
  <Fact label="Budget">At most 100 turns per run</Fact>
  <Fact label="Same conditions">The same harnesses, turn budget and execution environment</Fact>
</Facts>
